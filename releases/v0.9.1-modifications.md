## 修改范围

`com.follow.clash` 改为个人包名 `com.xigua.netapp`，同步替换清单中相关 permission、action、provider authority 与 `resources.arsc` 的资源包名。保留原有 Java/Kotlin 类名，未修改 DEX、原生库或 Flutter 资源。

公开脚本为 [tools/repackage_v0_9_1.py](../tools/repackage_v0_9_1.py)。使用 Python 3 执行：

```sh
python3 tools/repackage_v0_9_1.py FlClash-0.9.1-android-arm64-v8a.apk FlClash-0.9.1-unsigned.apk
```

脚本仅生成**未签名中间文件**，不能直接安装；需要后续 ZIP 对齐和 APK 签名。不要用 Python 的 `-O` 参数运行，因为该脚本使用断言校验二进制结构。本脚本只适用于校验值匹配的 v0.9.1 ARM64 输入，不承诺适用其他版本。

本次发行使用 uber-apk-signer 1.3.0 完成对齐和签名，沿用 v0.9.0 个人版的本地签名密钥。工具来源：[patrickfav/uber-apk-signer](https://github.com/patrickfav/uber-apk-signer/releases/tag/v1.3.0)。所用 JAR SHA-256：

```text
e1299fd6fcf4da527dd53735b56127e8ea922a321128123b9c32d619bba1d835
```

自行制作时应使用自己的本地密钥；不同密钥生成的 APK 不能覆盖本仓库发行版，也不会得到相同文件哈希。私钥、密码与个人配置不包含在仓库中。
